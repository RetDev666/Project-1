# Тайм-менеджер - Веб-додаток для управління особистим часом

Сучасний веб-додаток для ефективного управління особистим часом з технікою Помодоро, трекінгом активностей та детальною аналітикою продуктивності.

## 🚀 Функціонал

### ✅ Планувальник завдань
- Створення, редагування та видалення завдань
- Встановлення пріоритетів (високий, середній, низький)
- Налаштування дедлайнів
- Фільтрація за статусом та пріоритетом

### ⏰ Техніка Помодоро
- Налаштовуваний таймер (робота/перерва/довга перерва)
- Автоматичне переключення між режимами
- Статистика завершених сесій
- Звукові сповіщення

### 📊 Трекінг часу
- Відстеження часу на різні активності
- Історія трекінгу з детальною статистикою
- Активні сесії з можливістю зупинки

### 📈 Аналітика продуктивності
- Графіки продуктивності за день/тиждень/місяць
- Аналіз використання часу
- Статистика сесій Помодоро
- Загальні показники ефективності

### 🚫 Блокування сайтів
- Додавання відволікаючих сайтів до чорного списку
- Перевірка URL на блокування
- Управління списком заблокованих ресурсів

### 🔔 Нагадування
- Налаштування перерв та вправ для очей
- Користувацькі нагадування
- Автоматичні сповіщення

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію
```bash
git clone <repository-url>
cd time-manager
```

### 2. Встановлення залежностей
```bash
npm install
```

### 3. Налаштування бази даних

Створіть базу даних MySQL:
```sql
CREATE DATABASE time_manager CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Створіть файл `.env` в корені проекту:
```env
DB_HOST=localhost
DB_USER=your_username
DB_PASSWORD=your_password
DB_NAME=time_manager
JWT_SECRET=your-secret-key-here
PORT=3000
```

### 4. Ініціалізація бази даних
```bash
npm run init-db
```

### 5. Запуск додатку
```bash
# Розробка з автоматичним перезавантаженням
npm run dev

# Продакшн
npm start
```

### 6. Відкриття в браузері
```
http://localhost:3000
```

## 🔧 API Endpoints

### Завдання
- `GET /api/tasks` - отримати всі завдання
- `POST /api/tasks` - створити завдання
- `PUT /api/tasks/:id` - оновити завдання
- `DELETE /api/tasks/:id` - видалити завдання

### Помодоро
- `GET /api/pomodoro/stats` - статистика
- `POST /api/pomodoro/session` - створити сесію
- `PUT /api/pomodoro/session/:id/complete` - завершити сесію
- `GET /api/pomodoro/history` - історія сесій

### Трекінг часу
- `POST /api/time-tracking/start` - почати трекінг
- `PUT /api/time-tracking/stop/:id` - зупинити трекінг
- `GET /api/time-tracking/active` - активні трекінги
- `GET /api/time-tracking/history` - історія

### Аналітика
- `GET /api/analytics/productivity` - продуктивність
- `GET /api/analytics/time-usage` - використання часу
- `GET /api/analytics/overview` - загальна статистика

### Заблоковані сайти
- `GET /api/blocked-sites` - список сайтів
- `POST /api/blocked-sites` - додати сайт
- `DELETE /api/blocked-sites/:id` - видалити сайт
- `POST /api/blocked-sites/check` - перевірити сайт

### Нагадування
- `GET /api/reminders` - список нагадувань
- `POST /api/reminders` - створити нагадування
- `PUT /api/reminders/:id` - оновити нагадування
- `DELETE /api/reminders/:id` - видалити нагадування
